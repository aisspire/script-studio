# Script Studio 当前设计

- 更新日期：2026-11-03。
- 用户已确认实现独立的额外插件，暂用 Script Studio 名称及 script-studio 身份。

## 产品与数据

管理已有的本地脚本文件。登记、备注、分组、收藏、解释器、参数、工作目录、环境变量和编码保存在本工具本地配置。原文件保留在原处，移除登记不删除原文件或运行历史；删除分组时脚本归入未分组。宿主只保存插件接入，不复制业务配置。

## 运行行为

- Windows 首版，支持自动识别、PowerShell、CMD、Python、Node.js、直接执行与自定义解释器。
- 不同脚本并发，同脚本最多一个托管实例。后台原子校验，前端禁用不是唯一保障。
- 运行使用启动快照，编辑仅影响后续运行；需要先停止活动运行才能移除脚本登记。
- 标准输出与标准错误作为普通文本日志，成功取决于退出码 0。脚本不需要实现 Oriel JSON 协议。
- 托管运行不接受 stdin；长任务可前台等待，不提供内嵌交互终端或内置调度。
- Windows Job 管理实际创建的进程树，主进程结束后仍有子进程时任务继续活动，退出码保留主进程结果。
- 切换、刷新和关闭页面继续运行；完整退出后台或接入后的 Oriel 完整退出清理本实例全部托管 Windows 进程树。外部进程不接管。
- WSL 由 Windows 包装脚本调用。首版不管理发行版、路径映射或 Linux 后台作业清理。

## 页面

左侧分组与收藏，中间可搜索和筛选的脚本列表，右侧逐脚本配置，底部运行输出和历史。默认空工作空间，不放置会误执行的示例脚本。浅深主题通过浏览器颜色偏好响应宿主；窄窗将配置收进可关闭的侧面板，保留键盘焦点与 Escape 操作。

分类栏和配置栏在桌面布局中支持调整宽度，输出面板支持调整高度。分隔条支持拖拽、方向键与复位，尺寸偏好由工具数据目录保存，后台重启或随机端口变化后仍可读取；保存独立于脚本配置，不改变脚本草稿的修订号。窗口缩小时临时限制显示尺寸，恢复空间后还原偏好，不将缩小结果写回保存值。

脚本卡片在运行按钮旁提供 PowerShell 命令复制，使用已保存配置；参数下方常驻的启动预览及复制使用当前草稿。命令采用可执行的 PowerShell 语法，复制不保存、不运行脚本，反馈剪贴板成功或失败；工作目录与环境变量使用粘贴目标终端的当前设置。运行三角形在图标内居中。

2026-10-27 已确认：按住 Ctrl 点击运行，直接打开外部 PowerShell 终端并启动已保存配置；原复制命令入口保留。外部运行复用执行器的解释器、参数、工作目录和环境变量，结束后保留终端。Ctrl 状态将运行图标切为终端、圆形按钮切为圆角方形并显示轻微脉冲；减少动效时保留静态状态，悬浮提示说明普通与 Ctrl 启动方式，松键、失焦或隐藏页面恢复。

外部启动相当于用户自行打开终端执行，不建立托管运行、日志或历史，不随后台或 Oriel 退出停止；停止和重复启动由用户在终端管理。存在同脚本托管任务时仍显示停止按钮，后台拒绝外部启动。此功能由工具自身实现，不新增宿主执行接口或内嵌终端。

2026-10-27 已确认：外部终端直接启动实际脚本或解释器，运行期间不依赖安装目录中的 Script Studio 主程序或辅助文件。修复原先通过主程序 `terminal-run` 等待脚本、导致外部任务占用待更新 exe 的问题。正常退出后台后，外部任务继续运行，允许替换插件目录；脚本结束显示退出码并保留可用终端。更新前仍需退出后台，脚本自身运行或加载安装目录内文件产生的占用需单独处理；不引入自动更新器，不迁移或终止已经运行的旧辅助进程。

复制、保存、重新加载等成功提示，以及全局操作错误和配置不可写提示，统一在右下角悬浮展示，不占布局空间、不移动脚本列表或输出面板。成功提示约 4 秒后自动消失，鼠标悬停或键盘聚焦时暂停；错误可手动关闭，配置错误保留重新加载操作。弹窗内操作的通知仍位于可见且可操作的弹窗顶层；字段校验和运行日志诊断保留在对应位置。断连提示关闭后不因轮询重复弹出，恢复连接后清除。

运行输出与当前配置分别关联运行身份和脚本身份。底部运行窗口默认收起（42px 摘要栏，展开后约 240px，可拖拽），打开程序时不自动读取历史记录日志，由用户在界面上主动点击读取。设置提供运行历史，包括已经移除登记的脚本；当前显示清空不清除持久化日志。历史最多保留 1 次已结束任务，每次日志上限 10 MiB，超限继续排空输出。

## 独立与宿主

Rust + Vue 3／TypeScript，使用自己的锁文件与目录包。单数据目录单后台，核验实例后复用；实例控制范围涵盖该实例全部任务。多宿主仲裁、自动安装更新、脚本编辑器和独立桌面外壳不属于首版。

Oriel 接入使用现有版本 2 声明、本地服务 stdio-v1、应用展示与随包说明，不新增宿主能力类型、Tauri 权限或配置字段。后台就绪与脚本运行状态是不同对象。

插件在声明中显式选择 `icon: "terminal"`，作为 Script Studio 自身的 Oriel 侧栏图标；不改变其他插件的默认展示。

## 2026-11-03：工作空间交互升级（已确认并实现）

用户要求保持 Rust HTTP／stdio 与执行逻辑兼容，升级列表、配置和控制台；仅修改独立前端与相关说明，不增加宿主能力或业务配置字段。

- 浅色采用 Slate 页面底色、白卡片、细边框和微阴影；深色区分页面、面板和卡片，选中项微光。绿色表示成功，紫色表示运行，红色表示失败／停止。路径、参数、环境变量和日志采用统一等宽字体。
- 列表提供卡片与 40px 紧凑行视图，名称可悬停查看完整内容；卡片显示前三个参数摘要和状态／耗时。方向键在脚本选择按钮间移动焦点，Enter 选择；Tab 可访问逐项操作。
- 配置字段独立滚动，保存、放弃和移除登记保持在底部。环境变量默认逐行 Key／Value 编辑，可切换纯文本；共用同一草稿，保留注释、等号和空值，实时检查名称格式及 Windows 大小写重复。纯文本不执行 shell 展开。命令预览常驻参数下方，复制语义沿用既有契约。
- 控制台提供 42px 折叠、标准高度和覆盖中右两栏的最大化模式；还原不覆盖已保存拖拽尺寸。默认收起面板，不主动读取已结束历史。全部／stdout／stderr 与关键词联合过滤，按流拼接跨块行后高亮字面匹配。Ctrl+F 聚焦搜索，Esc 关闭搜索或还原最大化；日志仍是只读输出。
- 运行按钮为主动作与菜单组合。菜单选择立即执行，成功启动后按脚本 ID 记忆 managed／external；失败和取消不改变偏好。Ctrl 点击始终强制外部终端，松键／失焦恢复图标，减少动效时无脉冲。活动托管运行继续显示停止按钮。复制不改变运行偏好。
- 列表视图与面板尺寸由数据目录的布局文件保存，不依赖后台端口。运行方式仍使用当前浏览器来源的 localStorage，存储不可用时保留会话内状态，端口变化或更换浏览器后可能回到默认值。

预览从高级折叠移到表单常驻区域，提高操作可达性；控制台按最新要求保持默认收起。保留外部终端进程归属、未保存草稿确认、配置修订冲突和历史保留规则。实际验证及平台范围见 [验证记录](../verification.md)。

### 同日确认：启动状态与配色收敛

用户要求历史面板保持默认关闭，重启后列表恢复“未运行”，并略微降低配色亮度。控制台初始保留 42px 摘要栏，主动运行或查看历史时展开。首次连接后台实例时，将已有的已结束记录归入历史，不再用于列表状态及耗时；本次新运行仍显示实时状态和最终结果。此展示边界按实例标识保存在当前来源，刷新页面不清除本次运行结果；历史及日志仍可主动查看，查看历史不会恢复列表旧状态。存储不可用时使用内存基线，再次加载页面会重新划分已有结束记录。紫色、成功／错误色及选中微光降低饱和度与亮度，保留文本对比和键盘焦点。

### 同日修复：紧凑视图跨重启保存

紧凑选择仅写 localStorage 时会随后台随机端口变化而丢失。现通过既有布局读写动作保存到 `ui-layout.json`，新增可选 `viewMode`（cards／compact），兼容无此字段的旧文件和请求；旧客户端仅更新尺寸时保留已保存视图。工具数据目录为权威，仅首次缺少该字段且当前来源有旧偏好时迁移一次。读取完成前禁用视图切换，保存失败显示提示，再次点击当前视图可重试保存；重启、换端口或换浏览器仍恢复同一数据目录的选择。需要配套更新后台与前端，宿主声明、脚本执行接口和配置版本保持不变。
